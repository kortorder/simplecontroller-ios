# Practice profiles

To try an example, save its JSON document to Files on the iPhone. Open Simple Controller, tap **Profiles**, then **Import iPhone profiles** and select the document. At large text sizes, start at **All controls → Profiles**. Import adds a copy to the library.

- [GTA 6 Prep](GTA-6-Prep.json) uses small round buttons, lower-left sticks, repeated A at full forward, and a direct Aim + fire pad on Walk. The sample controller mappings are provisional.
- [GTA V left side](GTA-V-Left-side.json) is the earlier one-finger layout.
- [Feature check](../docs/Feature-check-0.15.2.json) is a separate profile for trying editor and input behaviors.
